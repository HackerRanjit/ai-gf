What I’ve learned about you

I pick up lasting facts from our chats (like your name or what you like) and use them to talk better. Everything stays in this browser; delete anything you don’t want kept.

Teach me

Teach new replies (works offline). You can also type “learn: question => answer” in chat, or “forget: question”.

NVIDIA AI (real AI replies)

Paste your NVIDIA API key once to get real AI answers. It stays in memory for this tab; tick the box to remember it on this device only (it is never included in exports). Anyone using this browser profile could read it, so use a key you can revoke.

AI connector (optional)

Enter the URL of your own server or local model endpoint. It receives POST JSON {mode, name, messages} and must return {"reply": "…"}. Never put secret API keys here: keep them on the server side. Without a connector, replies come from the offline rule-based brain.

Data & privacy

Everything is stored in this browser’s LocalStorage on this device only and isn’t synced between Windows and Android; use export/import to move it. No passwords or API keys are stored.

Offline: save this page as a file and open it locally. Chat, teaching, tasks, notes, reminders, timers and the avatar then work without internet (the image is embedded). Voice input in Chrome normally needs internet unless on-device recognition is available; spoken replies use the voices installed on your device.

Shortcuts: Alt+1…9 switch sections, Alt+M mic, Alt+T theme.
